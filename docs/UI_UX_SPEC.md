# UI / UX Specification

## Primary navigation

Home; Physics Lab; Chemistry Lab; Biology Lab; My Practicals; Progress; Settings/Profile (optional, no account required initially).

## Dashboard

1. App name and class selection.
2. Three subject entry points.
3. Continue practical/recently used section.
4. Guided Practice, Free Practice and Practical Exam entry points.
5. Progress summary and offline-pack status.

## Subject landing page

Show class and subject; searchable practical catalogue with topic/type filters; inventory preview; and practical cards with syllabus mapping/readiness status. Selecting a practical opens its workbench, not only an article page.

## Workbench

Empty canvas on a new session; equipment tray with search/categories; tap/drag placement; object selection and contextual actions; live result/analysis dashboard; step guide in Guided mode; notebook and reset controls.

On mobile, tray and analysis are collapsible bottom sheets. Keep the workbench primary.

## Interaction language

Use clear verbs: Place, Connect, Add sample, Measure, Focus, Observe, Record, Undo and Reset. Explain why an action is unavailable. Use standard scientific names, symbols and SI units.

## Exam and feedback

Practical exam hides hints by default, presents required setup/actions and scores method, observation, calculation, record and viva separately. After submission, show a worked review and explain mistakes.
