## Important distinction: CIET index versus syllabus

- CIET index shows learning resources and linked lab manual exercises; it is not a board's binding exam practical list.
- For each item store source_pack = NCERT_CIET and a separate board_mapping = RBSE only when the official RBSE syllabus explicitly supports it.
- A title in the index does not mean its full procedure, safety, model or asset is already audited.
- Full subject manuals and linked DIKSHA activities still need review where needed.
- The index also includes Computer Science and Mathematics activities; these are not included in this first three-science-subject crosswalk, but could be future platform modules.
