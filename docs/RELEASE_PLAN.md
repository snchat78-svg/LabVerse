# Release Plan

## Release 0 — Design baseline
Scope and architecture documents stored. No application implementation is claimed.

## Release 1 — Syllabus-backed prototype
One approved representative practical in each subject; core 3D placement; deterministic experiment state and live observations; basic notebook/guided steps; offline smoke test on Android.

## Release 2 — Practical learning beta
Wider class/subject catalogue; expanded Chemistry, Physics and Biology engines; free mode, exam mode, viva and scoring; progress and content pack management; mobile performance/accessibility checks.

## Release 3 — Android release candidate
PWA verified; Capacitor Android package produced; device matrix, offline tests, safety and scientific review; defect triage and versioned content updates. Distribution route chosen using current cost/store requirements.

No release can be labelled ready while high-severity scientific correctness or safety defects remain open.
