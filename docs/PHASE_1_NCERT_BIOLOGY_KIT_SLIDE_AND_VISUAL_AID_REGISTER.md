## 4. Asset acceptance template

Every candidate record should later add:
- English/common name and accepted scientific name with taxonomy authority/version, aliases and taxon ID where relevant.
- source edition, exact manual card/slide ID, source date and item quantity evidence;
- original/licensed 3D/image source, licence, attribution and content hash;
- required visible structures and features, reviewer, confidence and unsupported cases;
- geometry scale, dimensions/bounding box, pivot, LOD, camera/magnification behaviour and accessible text/keyboard alternative;
- data relationship to the RBSE task IDs in docs/PHASE_1_RBSE_ALL_PRACTICAL_COVERAGE_REGISTER.md;
- safety state, whether a simulated specimen/prepared slide only, and whether collection/handling is prohibited;
- validation image set and test-vector references.

## 5. Source mismatch / limitations

1. The kit manual lists 60 exercises using a separate numbering sequence (XI 1–34, XII 35–60). Do not confuse these with later NCERT Biology Laboratory Manual exercise numbers or RBSE practical item numbers. Link by topic, source and edition.
2. The manual transcription's front matter states first edition March 2018, reprints through March 2020, ALL RIGHTS RESERVED and distribution only with the kit. A secondary-hosted transcript does not authorise redistribution.
3. The manual's 58 chemical/reagent/stain entries are not supplied with the kit, and one blade entry is specifically not supplied; do not present them as available kit inventory.
4. This candidate register is not the procurement spec for the Biology-with-microscope and Biology-without-microscope variants.
5. No physical 3D assets, learner experiment engine, expert-approved taxonomy or scientific software tests are implemented.
6. Status for all records in this file: SECONDARY_TRANSCRIPTION_ONLY / DESIGN_ONLY / PRIMARY_MATCH_PENDING.
