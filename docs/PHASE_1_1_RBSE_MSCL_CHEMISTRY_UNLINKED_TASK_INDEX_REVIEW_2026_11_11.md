1. The NCERT contents index is a locator, not a complete procedure. We did not read the full experiment body for crystallisation, melting/boiling point, equilibrium, pH, titrimetry, salt analysis or Lassaigne's test.
2. The CIET page is an activity listing. It does not by itself provide an approved reagent set or grant permission to reproduce the underlying content.
3. For qualitative analysis (XI PRA-18 and XII QUAL-01), the presence of cation/anion test titles does not establish an exact salt, reagent BOM, group separation sequence, concentrations or gas-test controls.
