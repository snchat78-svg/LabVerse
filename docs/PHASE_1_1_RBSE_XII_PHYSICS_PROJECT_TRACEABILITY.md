## 3. Proposed scientific model scope and planned test vectors

### RBSE-XII-PHY-PRJ-01 — Laser wavelength by diffraction

**Proposed model:** PHY-LASER-WAVELENGTH-DIFFRACTION. For a known slit/grating spacing d and order m, d sinθ=mλ; for a small-angle single slit minima use a sinθ=mλ. Method and optical element must be specified.

**Planned tests (NOT RUN):** TV-XII-PHY-PRJ-01-WAVELENGTH-REFERENCE; TV-XII-PHY-PRJ-01-SLIT-SPACING; TV-XII-PHY-PRJ-01-ORDER; TV-XII-PHY-PRJ-01-SMALL-ANGLE; TV-XII-PHY-PRJ-01-SCREEN-DISTANCE.

**Safety:** All circuits and radiation comparisons are virtual and bounded. No laser/IR source handling, mains circuitry or live high-power electrical assembly instructions.

**Source gap:** No laser source or calibrated slit/grating is explicitly listed; blade row is not a safe learner asset. Need wavelength source/diffraction element specs.

**Review:** Require Physics/electronics subject-expert review for source match, device datasheets, calibration, uncertainty, model validity and safety. Original assets and text need rights review.
