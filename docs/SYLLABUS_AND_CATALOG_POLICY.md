# Syllabus and Practical Catalogue Policy

## Authority order

1. Current official RBSE syllabus/practical instructions for the selected examination session are primary for the Rajasthan board catalogue.
2. Official NCERT Class XI/XII laboratory manuals and kit manuals support procedure, apparatus and scientific context.
3. CBSE curriculum may be a separately tagged comparison/compatibility source; it must not override RBSE requirements.
4. Secondary websites may help locate a source but cannot be final evidence for a syllabus claim.

## Every catalogue row must include

Stable ID/title; board/class/subject/session; exact official document/page/section/URL; practical/activity/project/spotting/record/viva category; learning objective/prerequisites; apparatus/instruments/glassware/chemicals/specimens; procedure and allowed simulated actions; observations and expected outcomes; equations/calculations/units; 3D assets and interactions; safety/supervision tags; author/reviewer/verification date; current status and version.

## Completeness process

1. List official documents available for each class and subject.
2. Record title, academic session, publication date, retrieval date and checksum.
3. Extract all practicals, activities, projects, investigatory work, specimen/slide/spotting tasks, records and viva requirements.
4. Build coverage matrix: source item -> catalogue item -> app feature -> test.
5. Compare headings and practical totals against source documents.
6. Mark unclear or changing items NEEDS_REVIEW.
7. Have content checked before VERIFIED.
8. Repeat audit when RBSE issues a new syllabus.

Do not claim all RBSE practicals are included until the coverage matrix has no unexplained gaps and a reviewer has signed off.
